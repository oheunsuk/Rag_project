# 발표 데모 스크립트 (workcheck-rag)

## 1. 오프닝 (30초)

> 안녕하세요. **근무체크 RAG**는 고용노동부 공식 노동자료를 기반으로 근로계약·근무조건 질문에 답하는 서비스입니다.  
> 아르바이트 근로자와 소규모 사업주가 **순수 GPT 답변**과 **공식 문서 기반 RAG 답변**을 한 화면에서 비교할 수 있습니다.

## 2. 챗봇 데모 (2분)

**입력 질문:**
> 8시간 근무하면 휴게시간은 얼마나 줘야 하나요?

**멘트:**
> 먼저 질문 입력창에 위 문장을 입력하겠습니다.  
> 왼쪽은 **문서 검색 없이 GPT만 사용한 순수 LLM 답변**이고,  
> 오른쪽은 **FAISS Vector DB에서 공식 노동자료를 검색한 뒤 생성한 RAG 답변**입니다.  
> RAG 답변 아래 **「검색된 공식 문서 보기」**를 열면 실제 검색된 문서 chunk와 출처를 확인할 수 있습니다.  
> 이를 통해 단순 GPT 답변보다 **공식 근거 확인이 가능한 구조**임을 보여줍니다.

**추가 데모 질문:**
1. 2026년 적용 최저임금 시간급은 얼마인가요?
2. 근로계약서에 반드시 포함되어야 하는 항목은 무엇인가요?

## 3. 성능 평가 탭 (1분)

**멘트:**
> **성능 평가** 탭에서는 RAGAS 4지표 결과를 확인할 수 있습니다.  
> Ground Truth 12문항 기준 **평균 0.895**이며, Context Recall은 1.0입니다.  
> Top-k 비교 실험에서는 **k=5일 때 평균 0.891**로 가장 높았습니다.

| 지표 | 점수 |
|------|------|
| Faithfulness | 0.884 |
| Answer Relevancy | 0.852 |
| Context Precision | 0.845 |
| Context Recall | 1.000 |

## 4. 프로젝트 정보 탭 (30초)

**멘트:**
> 사용 문서는 표준근로계약서, 최저임금 보도자료, 근로시간·휴게시간 FAQ입니다.  
> 기술 스택은 Streamlit, LangChain, FAISS, OpenAI Embedding, RAGAS입니다.

## 5. 발표 강조 포인트

- 순수 LLM과 RAG 답변을 **같은 화면에서 비교**
- RAG 답변은 **공식 노동자료 chunk**를 근거로 생성
- 검색된 **문서와 출처**를 사용자가 직접 확인 가능
- **RAGAS 4지표**로 정량 평가 (Faithfulness, Answer Relevancy, Context Precision, Context Recall)
- Ground Truth **12개** 기준 평균 **0.895**
- Top-k 비교에서 **k=5**가 가장 높음
- 논문 제출로 **가점 항목** 수행
- GitHub에는 실행·평가에 필요한 파일만 정리

## 6. 교수님 평가 기준 대응

| 평가 항목 | 설명 포인트 |
|-----------|-------------|
| **UI** | 2열 비교 UI, 검색 문서 expander, 3탭 메뉴, 대화 기록 |
| **RAGAS** | 12문항 eval_dataset, 4지표 평가, 결과 CSV·차트 |
| **완성도** | ingest → vector DB → RAG → 평가 → 배포 파이프라인 완비 |
| **기술 우수성** | FAISS 검색, Top-k 실험, LLM vs RAG 비교, RAGAS 정량화 |
| **콘텐츠 우수성** | 고용노동부 공식 자료 3종, 근로계약·최저임금·휴게시간 도메인 |
